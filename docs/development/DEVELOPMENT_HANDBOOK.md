**Version:** 1.0

**Status:** LOCKED

---

# Purpose

This handbook defines how the Syaima Levantine website should be developed, maintained, and expanded.

It serves as the operational guide for every future implementation.

---

# Project Vision

Build a long-term knowledge hub focused on:

- AI for Pattern Design
- Microstock
- AI Productivity

Education always comes before promotion.

---

# Golden Rule

Documentation is the project's source of truth.

Every implementation must follow:

- Website Architecture
- Design System
- Development Handbook

# Decision Status

Every project decision must have one of these states:

- LOCKED
- CALIBRATION
- PLANNED

Only LOCKED decisions may be implemented.

---

# Development Principles

- Keep everything simple.
- Reuse components.
- Avoid unnecessary complexity.
- Do not duplicate components.
- Respect the Design System.
- Respect the Website Architecture.

---

# Definition of Done

A feature is complete only if it:

- follows the Website Architecture
- follows the Design System
- is responsive
- is accessible
- supports SEO
- supports AI Search
- passes review

# Git Workflow

Every change should follow this sequence:

1. Update documentation.
2. Implement the feature.
3. Test.
4. Commit.
5. Review.

---

# Repository Principle

The GitHub repository is the official source of truth.

Chat conversations are used for discussion.

Documentation records official decisions.

Source code implements those decisions.

---

# Future Development

Every new feature must answer:

- Does it help creators?
- Does it simplify the experience?
- Does it match the brand philosophy?
- Does it follow the Design System?

If the answer is no, the feature should not be implemented.
