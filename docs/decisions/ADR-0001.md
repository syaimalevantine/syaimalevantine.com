# ADR-0001

## Title

Website Architecture v1.0

---

## Status

LOCKED

---

## Context

The project requires a scalable architecture for multilingual content, products, and long-term growth.

---

## Decision

The website adopts:

- Homepage
- Products
- Blog
- About
- Contact

Supported languages:

- English
- Indonesian
- Arabic
- Turkish

The official Website Architecture document is the source of truth.

---

## Consequences

All future development must follow the Website Architecture document.
