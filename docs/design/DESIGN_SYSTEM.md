# Design System

**Project:** Syaima Levantine

**Version:** 1.0

**Status:** LOCKED

---

# Purpose

This document defines the official visual language and design principles for the Syaima Levantine website.

All UI components, pages, and future products must follow this design system.

---

# Brand Philosophy

Knowledge Hub

AI for Pattern, Microstock & Productivity

---

# Design Principles

- Calm before impressive.
- Simplicity before complexity.
- Education before promotion.
- Human before AI.
- Consistency over creativity.
- White space is part of the design.

---

# Editorial Principles

Writing should be:

- Practical
- Educational
- Honest
- Easy to read
- Experience-driven

Avoid:

- Clickbait
- Fake urgency
- Keyword stuffing
- Over-promising

---

# Homepage Hero

Characteristics:

- Full-screen layout
- Centered brand logo
- Olive photography background
- Minimal navigation
- Large negative space
- Two primary call-to-action buttons

Homepage tagline:

**Knowledge Hub | AI for Pattern, Microstock & Productivity**

---

# Visual Identity

Mood:

- Mediterranean
- Olive
- Stone
- Bone
- Natural
- Elegant
- Timeless

---

# Theme System

Adaptive Theme

Supports:

- Light Mode
- Dark Mode

Homepage Hero always uses the premium dark presentation.

---

# Typography

Style:

- Apple-inspired
- Clean
- Modern
- Highly readable

Current calibration:

- H1: 16px
- H2: 12px Bold
- H3: 12px SemiBold
- Body: 12px

Typography should emphasize hierarchy through font weight rather than large font sizes.

---

# Color Philosophy

Colors should support the content, never dominate it.

Primary inspiration:

- Olive
- Bone
- Stone
- Charcoal

Photography is the primary visual element.

---

# Spacing System

Based on an 8px scale.

Spacing values:

- 4
- 8
- 16
- 24
- 32
- 48
- 64
- 96

Generous white space is encouraged.

---

# Border Radius

Standard values:

- Small
- Medium
- Large
- Pill

Use consistent radius throughout the project.

---

# Shadow

Use minimal shadows.

If a shadow is unnecessary, remove it.

---

# Motion

Allowed:

- Fade
- Opacity
- Smooth hover
- Smooth scrolling

Avoid:

- Bounce
- Flash
- Shake
- Distracting animations

---

# Accessibility

The design must support:

- High contrast
- Keyboard navigation
- Visible focus state
- Alt text
- RTL (Arabic)
- Reduced motion

---

# Component Philosophy

Every component should be:

- Reusable
- Consistent
- Minimal
- Scalable

One purpose.

One component.

---

# Logo Usage

Primary Logo

Used on:

- Homepage
- About
- Footer

Symbol Logo

Used on:

- Article thumbnails
- Favicon
- Author avatar
- Small UI elements

# Anti-Patterns

Never use:

- Fake countdowns
- Aggressive popups
- Flashing banners
- Clickbait
- Keyword stuffing
- Excessive animations
